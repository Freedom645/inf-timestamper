## v1.2.0-alpha.1（α 版）

**SOUND VOLTEX 対応の動作確認用のプレリリースです。** 実機での通し確認が済んでいないため、正式版ではありません。INFINITAS / pop'n music を普段どおり使いたい方は v1.1.0 をお使いください。

この α 版をインストールしている間は、起動時のバージョンチェックで次の α 版も更新候補になります。正式版 v1.2.0 が出た時点でそちらへ更新されます。

### 新機能

- **SOUND VOLTEX に対応しました。** プレイ検知は [SDVX Helper](https://github.com/dj-kata/sdvx_helper) v2 系のデータ配信 WebSocket（既定 `ws://127.0.0.1:8767`）を購読して行います。v1 系（`out/history_cursong.xml` を出力する版）には対応していません
  - 曲を決定した時刻をプレイ開始として記録し、SDVX Helper がリザルトを登録した時点で成績を紐づけます
  - 識別子は `$grade` / `$clear_lamp` / `$score` / `$score_short` / `$ex_score` と、共通の `$timestamp` / `$title` / `$level` / `$diff_l` / `$diff_s`
  - 設定ウィンドウに SOUND VOLTEX タブが増え、SDVX Helper の接続先（ホスト・ポート）とタイムスタンプ書式を設定できます
- 設定ウィンドウの識別子セレクトボックスと `$` 入力時の候補が「論理名 ($識別子)」の表記になりました

### 確認してほしいこと

- SDVX Helper v2 系を起動し、SOUND VOLTEX タブのポートを SDVX Helper の「WebSocketデータ配信ポート」に合わせた状態で、曲を決定するたびにタイムスタンプが 1 件ずつ増えるか
- 選曲画面でカーソルを動かしただけではタイムスタンプが増えないか
- リザルトの成績が、直前のプレイではなくそのプレイに紐づくか
- INFINITAS / pop'n music の記録がこれまでどおり動くか

### 必要なもの

- Windows 10 / 11 (x64)
- INFINITAS: [Reflux](https://github.com/olji/Reflux)
- pop'n music: `state.txt` / `result.json` を出力する外部トラッカー（別途用意。詳細は README）
- SOUND VOLTEX: [SDVX Helper](https://github.com/dj-kata/sdvx_helper) v2 系（本アプリと同じ PC で動かす）
- OBS Studio 28 以降（配信開始/終了の自動検知に使用。任意）

### インストール時の注意

`InfTimestamper-win-Setup.exe` を実行すると **「WindowsによってPCが保護されました」** と表示されます。個人開発の無償ツールのためコード署名証明書を取得しておらず、Windows SmartScreen が警告を出すためです。

続けるには **「詳細情報」→「実行」** を選択してください。ソースコードはすべてこのリポジトリで公開しています。
