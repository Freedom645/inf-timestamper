## v1.2.0

**SOUND VOLTEX に対応しました。** 対応ゲームは INFINITAS / pop'n music / SOUND VOLTEX の 3 つになります。

### 新機能

- **SOUND VOLTEX に対応しました。** プレイ検知は [SDVX Helper](https://github.com/dj-kata/sdvx_helper) v2 系と連携して行います
  - 設定ウィンドウに **SOUND VOLTEX タブ**が増えました。SDVX Helper の**フォルダ**（`sdvx_helper.exe` がある場所）と**データ配信ポート**（既定 8767）を指定してください
  - プレイ画面に入った時刻をプレイ開始として記録し、SDVX Helper がリザルトを登録した時点で成績を紐づけます。**リザルト画面からのリトライも記録されます**
  - 使える識別子は `$grade` / `$clear_lamp` / `$score` / `$score_short` / `$ex_score` と、他ゲームと共通の `$timestamp` / `$title` / `$level` / `$diff_l` / `$diff_s` です
  - **SDVX Helper と本アプリは同じ PC で動かしてください。** SDVX Helper のデータ配信は localhost にしか待ち受けません
  - SDVX Helper v1 系（`out/history_cursong.xml` を出力する版）には対応していません
- **識別子が「論理名 ($識別子)」で表示されるようになりました。** 設定ウィンドウのセレクトボックスと、`$` 入力時の候補の両方が対象です（例: `タイトル ($title)`）

### 改善

- SOUND VOLTEX タブでは、接続先ホストを変更できます（既定 `127.0.0.1`。ポートフォワード等を挟む場合用）
- プレイ検知の動作がログ（`logs\app_yyyyMMdd.log`）に残るようになりました。記録が合わないときの原因調査に使えます

### 必要なもの

- Windows 10 / 11 (x64)
- INFINITAS: [Reflux](https://github.com/olji/Reflux)
- pop'n music: `state.txt` / `result.json` を出力する外部トラッカー（別途用意。詳細は README）
- SOUND VOLTEX: [SDVX Helper](https://github.com/dj-kata/sdvx_helper) v2 系（本アプリと同じ PC で動かす）
- OBS Studio 28 以降（配信開始/終了の自動検知に使用。任意）

### 設定ファイル・記録ファイルについて

v1.1.0 からそのまま引き継げます。設定ファイルに SOUND VOLTEX の項目が無い場合は既定値で補われます。

### インストール時の注意

`InfTimestamper-win-Setup.exe` を実行すると **「WindowsによってPCが保護されました」** と表示されます。個人開発の無償ツールのためコード署名証明書を取得しておらず、Windows SmartScreen が警告を出すためです。

続けるには **「詳細情報」→「実行」** を選択してください。ソースコードはすべてこのリポジトリで公開しています。
