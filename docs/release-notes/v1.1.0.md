## v1.1.0

実機での配信検証で見つかった不具合の修正が中心です。**v1.0.0 では配信開始日時が記録されず、タイムスタンプが正しく出ないケースがありました。** v1.0.0 をお使いの方は更新をおすすめします。

### 新機能

- **タイムスタンプの先頭に「配信開始」行を入れられるようになりました。** YouTube のチャプタ機能は先頭が 0 秒のチャプタであることを要求するため、既定でオンです。`基本設定タブ` で表示の有無と見出し文言を変更できます
- **配信中にアプリを起動しても記録を開始できるようになりました。** これまでは OBS の配信開始イベントを待つだけだったため、先に配信を始めているとずっと `配信開始待ち` のままでした
- 起動時の復旧ダイアログで、ファイル名・最終更新日時・タイムスタンプ件数が確認できるようになりました。選択肢に「削除する」（ゴミ箱へ送る）が加わり、未完了ファイルが複数ある場合は順に提示されます
- タイムスタンプの複数選択で、Shift+クリックの範囲選択と Ctrl+クリックの追加選択が使えるようになりました
- タイムスタンプ書式の入力欄で、`$` の直後に識別子の候補が出るようになりました（↑↓ で選択、Enter / Tab で確定、Esc で閉じる）
- バックアップ保存先と OBS のホストが不正な場合、入力欄が赤く表示されるようになりました
- 設定ウィンドウで OBS の接続情報や監視フォルダを変更したとき、いったん停止しなくてもその場で反映されるようになりました

### 修正

- **OBS の配信開始を検知しても配信開始日時が記録されず、各タイムスタンプの時間が巨大な値になる問題を修正しました。**「強制開始」ボタンでしか日時が入っていませんでした。同じ理由で、OBS の配信終了を検知したときに配信終了日時が記録されない問題も直っています
- **配信開始日時が `-` のままだと編集できず、上記の状態から復旧できない問題を修正しました。** タイムスタンプが 1 件以上あれば編集でき、初期値には先頭のタイムスタンプの時刻が入ります
- **記録が自動保存されていませんでした。** 配信開始時・プレイ記録の追加時・時間の編集時・記録終了時・アプリ終了時に、バックアップ保存先へ自動で書き出すようになりました。あわせて、保存済みなのにアプリ終了時に「未保存の記録があります」と警告される問題も直っています
- 最初のタイムスタンプがリストに二重表示され、しばらくすると消える問題を修正しました
- アプリのタイトルバーにバージョンを表示するようにしました

### 記録ファイルの変更

読み込みの互換性は保たれていますが、書き出す内容が変わります。

- 日時を秒単位で書き出すようになりました（これまでは 1 秒未満の端数が入っていました）
- `level` / `miss_count` / `ex_score` / `score` / `bad` を文字列ではなく数値で書き出すようになりました
- 改行コードを LF に統一しました
- `app.version` に実際のアプリバージョンが入るようになりました

### v1.0.0 で壊れた記録ファイルの救済

配信開始日時が入らなかった記録は、ファイルを開いて配信開始日時を右クリックから編集すれば正しい相対時刻に直せます。

### 必要なもの

- Windows 10 / 11 (x64)
- INFINITAS: [Reflux](https://github.com/olji/Reflux)
- pop'n music: `state.txt` / `result.json` を出力する外部トラッカー（別途用意。詳細は README）
- OBS Studio 28 以降（配信開始/終了の自動検知に使用。任意）

### インストール時の注意

`InfTimestamper-win-Setup.exe` を実行すると **「WindowsによってPCが保護されました」** と表示されます。個人開発の無償ツールのためコード署名証明書を取得しておらず、Windows SmartScreen が警告を出すためです。

続けるには **「詳細情報」→「実行」** を選択してください。ソースコードはすべてこのリポジトリで公開しています。
