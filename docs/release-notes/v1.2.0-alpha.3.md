## v1.2.0-alpha.3（α 版）

**SOUND VOLTEX 対応の動作確認用のプレリリースです。** 正式版ではありません。INFINITAS / pop'n music を普段どおり使いたい方は v1.1.0 をお使いください。

α.2 で報告のあった「記録が二重で出る」「空の記録が出る」を修正しました。

### α.2 からの変更

- **1 プレイが複数件のタイムスタンプになる問題を修正しました。** SDVX Helper の画面判定は暗転・演出・ロード中に頻繁に「判定不能」へ落ちるため、1 プレイの途中でも「プレイ画面に入った」というログが何度も出ていました。判定不能は画面が変わったわけではないものとして読み飛ばし、**別の画面からプレイ画面に入ったときだけ**プレイ開始として扱うようにしています
  - 実機ログ（2026-09-23 の約 2 時間半）で検算すると、これまで 97 件のタイムスタンプになっていた区間が、実際のプレイ数と同じ 38 件になります
- **中身が空のタイムスタンプが残る問題を修正しました。** 上記で余分に作られていたエントリが原因です
- **SDVX Helper が同じプレイのリザルトを 2 回登録した場合に、2 件目を拾わないようにしました**
- **リトライしたプレイにも曲名・難易度・レベルが入るようになりました。** 直前に決定した譜面の情報をそのまま使います
- **ログに動作の記録を残すようにしました。** 記録が合わないときは、アプリのフォルダの `logs\app_yyyyMMdd.log` に `SDVX:` で始まる行が出ます（プレイ画面への遷移、曲決定画面の検知、リザルトの採否）。SDVX Helper 側の `log\sdvx_helper.log` と突き合わせると原因を追えます

### 確認してほしいこと

SOUND VOLTEX タブで **SDVX Helper のフォルダ** と **データ配信ポート** を設定した状態で:

- 1 プレイにつきタイムスタンプが 1 件になっているか
- 中身が空のタイムスタンプが出ないか
- リトライでもタイムスタンプが増え、曲名が入るか

合わない場合は、`logs\app_yyyyMMdd.log` と SDVX Helper 側の `log\sdvx_helper.log` の両方を見せていただけると助かります。

### α.1 / α.2 から引き継ぐ内容

- SOUND VOLTEX に対応（[SDVX Helper](https://github.com/dj-kata/sdvx_helper) v2 系のデータ配信 WebSocket を購読。v1 系には非対応）
- 識別子は `$grade` / `$clear_lamp` / `$score` / `$score_short` / `$ex_score` と、共通の `$timestamp` / `$title` / `$level` / `$diff_l` / `$diff_s`
- 設定ウィンドウの識別子セレクトボックスと `$` 入力時の候補が「論理名 ($識別子)」の表記に

### 必要なもの

- Windows 10 / 11 (x64)
- INFINITAS: [Reflux](https://github.com/olji/Reflux)
- pop'n music: `state.txt` / `result.json` を出力する外部トラッカー（別途用意。詳細は README）
- SOUND VOLTEX: [SDVX Helper](https://github.com/dj-kata/sdvx_helper) v2 系（本アプリと同じ PC で動かす）
- OBS Studio 28 以降（配信開始/終了の自動検知に使用。任意）

### インストール時の注意

`InfTimestamper-win-Setup.exe` を実行すると **「WindowsによってPCが保護されました」** と表示されます。個人開発の無償ツールのためコード署名証明書を取得しておらず、Windows SmartScreen が警告を出すためです。

続けるには **「詳細情報」→「実行」** を選択してください。ソースコードはすべてこのリポジトリで公開しています。
