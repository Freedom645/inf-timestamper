## v1.0.0

Python 実装（v0.6.1）から **C# / .NET 8 / WPF への全面リライト**です。

### 新機能

- **pop'n music に対応しました。** メインウィンドウのゲーム選択で INFINITAS と切り替えます（1 配信 = 1 ゲーム）
- **アプリ内で自動アップデート**できるようになりました。起動時に新バージョンを検出し、確認のうえ更新・再起動します（設定でオフにできます）
- **.NET ランタイムのインストールが不要**になりました（単一 exe に同梱）
- インストーラ形式（`Setup.exe`）を用意しました。展開配置したい場合は `Portable.zip` も使えます

### 変更

- タイムスタンプの識別子を整理しました。`$timestamp` / `$title` / `$level` / `$diff_l` / `$diff_s` はゲーム共通、成績系はゲームごとに分かれています
  - INFINITAS: `$dj_level` / `$lamp` / `$ex_score` / `$miss_count`
  - pop'n music: `$rank` / `$medal` / `$score` / `$bad`
- タイムスタンプの書式はゲームごとに別々に保存されます
- `配信開始待ち` のあいだは、リセットボタンが「停止」に変わり待機を解除できます

### 破壊的変更

- **v0.x で作成した記録ファイル・設定ファイルは読み込めません。** 保存形式を刷新したため、v1.0 では新規に作り直してください
- 設定は初期状態から入力し直す必要があります（Reflux の出力フォルダ、OBS の接続情報、タイムスタンプ書式）

### 必要なもの

- Windows 10 / 11 (x64)
- INFINITAS: [Reflux](https://github.com/olji/Reflux)
- pop'n music: `state.txt` / `result.json` を出力する外部トラッカー（別途用意。詳細は README）
- OBS Studio 28 以降（配信開始/終了の自動検知に使用。任意）

### インストール時の注意

`InfTimestamper-win-Setup.exe` を実行すると **「WindowsによってPCが保護されました」** と表示されます。個人開発の無償ツールのためコード署名証明書を取得しておらず、Windows SmartScreen が警告を出すためです。

続けるには **「詳細情報」→「実行」** を選択してください。ソースコードはすべてこのリポジトリで公開しています。
