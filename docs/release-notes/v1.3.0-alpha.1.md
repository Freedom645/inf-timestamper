## v1.3.0-alpha.1（α 版）

**YouTube の概要欄の自動更新の動作確認用のプレリリースです。** 実際の配信での通し確認が済んでいないため、正式版ではありません。普段どおり使いたい方は v1.2.0 をお使いください。

この α 版をインストールしている間は、起動時のバージョンチェックで次の α 版も更新候補になります。正式版 v1.3.0 が出た時点でそちらへ更新されます。

### 新機能

- **YouTube ライブ配信の概要欄を、記録中のタイムスタンプで自動更新できるようになりました**（任意機能。既定は OFF）
  - 記録中に、配信開始時間の前後 10 分以内に始まった自分の配信中のライブを探し、その概要欄の末尾へタイムスタンプを書き込み続けます
  - 概要欄の見出し行（既定 `▼タイムスタンプ`）から末尾までを書き換えます。見出し行が無ければ末尾に追記するので、手書きの説明文は残ります
  - YouTube API の 1 日の上限を節約するため、書き込みは最短 60 秒間隔（設定で変更可）にまとめます。記録停止時は間隔を待たずに最終版を書き込みます
  - メイン画面の「状態」の右に `YouTube:` として連携状態が表示されます。失敗してもダイアログは出さず、配信の記録にも影響しません
- 設定ウィンドウに「YouTube 連携」タブを追加しました

**利用には、各自で Google Cloud の OAuth クライアント（デスクトップ アプリ）を作成する必要があります。** API の利用上限をアプリの利用者全員で分け合わずに済むようにするためです。作成手順は [docs/youtube.md](https://github.com/Freedom645/inf-timestamper/blob/feature/youtube-description-sync/docs/youtube.md) を参照してください。ログイン情報は Windows の DPAPI で暗号化して PC 内に保存し、Google 以外には送信しません（[プライバシーポリシー](https://github.com/Freedom645/inf-timestamper/blob/feature/youtube-description-sync/docs/privacy.md)）。

### 確認してほしいこと

- OBS で配信を始めてから、メイン画面の `YouTube:` が「配信を検索中」→「連携中（配信タイトル）」に変わるか、変わるまでにどれくらいかかるか
- プレイ後、最短 60 秒以内に概要欄が書き換わるか。手書きの説明文やタイトル・タグが変わらずに残るか
- 記録を停止したときに、最後のプレイまで含んだ最終版が書き込まれるか
- INFINITAS / pop'n music / SOUND VOLTEX の記録がこれまでどおり動くか

### 必要なもの

- Windows 10 / 11 (x64)
- INFINITAS: [Reflux](https://github.com/olji/Reflux)
- pop'n music: `state.txt` / `result.json` を出力する外部トラッカー（別途用意。詳細は README）
- SOUND VOLTEX: [SDVX Helper](https://github.com/dj-kata/sdvx_helper) v2 系（本アプリと同じ PC で動かす）
- OBS Studio 28 以降（配信開始/終了の自動検知に使用。任意）
- YouTube 連携を使う場合: Google Cloud の OAuth クライアント（無料。上記の手順を参照）

### インストール時の注意

`InfTimestamper-win-Setup.exe` を実行すると **「WindowsによってPCが保護されました」** と表示されます。個人開発の無償ツールのためコード署名証明書を取得しておらず、Windows SmartScreen が警告を出すためです。

続けるには **「詳細情報」→「実行」** を選択してください。ソースコードはすべてこのリポジトリで公開しています。
