## v1.4.0-alpha.2（α 版）

**INFINITAS のプレイ検知に打鍵カウンタを使えるようにした版の、動作確認用のプレリリースです。** v1.4.0-alpha.1 の実機確認で見つかった不具合を直しました。普段どおり使いたい方は v1.2.0 をお使いください。

> [!WARNING]
> この版には v1.3.0-alpha.1 の **YouTube 概要欄の自動更新は含まれていません**。v1.3.0-alpha.1 をインストールしている PC では、起動時のバージョンチェックでこの版が更新候補になり、更新すると YouTube 連携が使えなくなります。YouTube 連携の確認を続ける PC では、この版への更新を見送ってください。

この α 版をインストールしている間は、起動時のバージョンチェックで次の α 版も更新候補になります。正式版が出た時点でそちらへ更新されます。

### 修正

- 打鍵カウンタを検知元にしたとき、**途中落ち・途中終了したプレイのミスカウント（`$miss_count`）が 700 や 1000 といった大きな値になる**不具合を直しました
  - 打鍵カウンタは途中落ちのとき、残りのノーツをすべて POOR として数えます。ゲームのリザルト画面と同じく、途中落ち・途中終了したプレイではミスカウントを空欄にします
  - 完走してゲージ不足で FAILED になったプレイのミスカウントは、これまでどおり記録します
  - クリアランプ（FAILED）と EX スコアは、途中落ちでも記録します

### 確認してほしいこと

- 途中落ち・途中終了したプレイで、ミスカウントが空欄になるか（ランプと EX スコアは入るか）
- 完走して FAILED になったプレイで、ミスカウントが入るか
- それ以外のプレイが v1.4.0-alpha.1 と同じく記録されるか

### v1.4.0-alpha.1 からの新機能（再掲）

- **INFINITAS のプレイの検知元として、Reflux の代わりに[打鍵カウンタ](https://github.com/dj-kata/inf_daken_counter_obsw)を選べるようになりました**（既定は Reflux のまま）
  - 設定ウィンドウの INFINITAS タブの「プレイの検知元」で `打鍵カウンタ` を選び、接続先（ホスト・ポート）を指定します
  - 打鍵カウンタを別の PC（ゲーム PC など）で動かしている場合は、その PC の IP アドレスを指定できます
  - 既定のポート 8767 は SDVX Helper と同じです。両方を常駐させる場合はどちらかのポートを変えてください
  - 打鍵カウンタはプレイ開始を直接知らせないため、**プレイが終わった時点で開始時刻をさかのぼって記録します。** タイムスタンプがリストに増えるのはプレイ終了時です
  - Reflux では拾えない**クイックリトライも 1 回ずつ記録されます**

### 必要なもの

- Windows 10 / 11 (x64)
- INFINITAS: [Reflux](https://github.com/olji/Reflux) または [打鍵カウンタ](https://github.com/dj-kata/inf_daken_counter_obsw)（v3.0.22 で確認）
- pop'n music: `state.txt` / `result.json` を出力する外部トラッカー（別途用意。詳細は README）
- SOUND VOLTEX: [SDVX Helper](https://github.com/dj-kata/sdvx_helper) v2 系（本アプリと同じ PC で動かす）
- OBS Studio 28 以降（配信開始/終了の自動検知に使用。任意）

### インストール時の注意

`InfTimestamper-win-Setup.exe` を実行すると **「WindowsによってPCが保護されました」** と表示されます。個人開発の無償ツールのためコード署名証明書を取得しておらず、Windows SmartScreen が警告を出すためです。

続けるには **「詳細情報」→「実行」** を選択してください。ソースコードはすべてこのリポジトリで公開しています。
