## v1.2.0-alpha.2（α 版）

**SOUND VOLTEX 対応の動作確認用のプレリリースです。** 正式版ではありません。INFINITAS / pop'n music を普段どおり使いたい方は v1.1.0 をお使いください。

α.1 の実機確認で「2〜3 回に 1 回記録されない」「リトライ時に記録されない」ことが分かったので、プレイ開始の検知方法を変えています。

### α.1 からの変更

- **SOUND VOLTEX タブに「SDVX Helper のフォルダ」が増えました。必ず指定してください。** `sdvx_helper.exe` があるフォルダです
  - SDVX Helper のログ（`log\sdvx_helper.log`）からプレイ画面に入った時刻を拾い、これをプレイ開始として記録します
  - **リザルト画面からのリトライも記録されるようになりました**
  - 曲決定画面を SDVX Helper が取りこぼした場合（α.1 で 2〜3 回に 1 回起きていた抜け）も記録されます
  - 未指定の場合は α.1 と同じ動作（曲決定画面の検知のみ）になります

### 確認してほしいこと

- SOUND VOLTEX タブで **SDVX Helper のフォルダ** と **データ配信ポート** を設定した状態で:
  - リトライでもタイムスタンプが増えるか
  - 曲決定画面を経由したプレイが二重に記録されないか（1 曲 1 件のまま）
  - α.1 で抜けていたプレイが記録されるか
  - リトライしたプレイの成績（`$score` 等）と曲名がそのプレイのものになっているか

### α.1 から引き継ぐ内容

- SOUND VOLTEX に対応（[SDVX Helper](https://github.com/dj-kata/sdvx_helper) v2 系のデータ配信 WebSocket を購読。v1 系には非対応）
- 識別子は `$grade` / `$clear_lamp` / `$score` / `$score_short` / `$ex_score` と、共通の `$timestamp` / `$title` / `$level` / `$diff_l` / `$diff_s`
- 設定ウィンドウの識別子セレクトボックスと `$` 入力時の候補が「論理名 ($識別子)」の表記に

### 必要なもの

- Windows 10 / 11 (x64)
- INFINITAS: [Reflux](https://github.com/olji/Reflux)
- pop'n music: `state.txt` / `result.json` を出力する外部トラッカー（別途用意。詳細は README）
- SOUND VOLTEX: [SDVX Helper](https://github.com/dj-kata/sdvx_helper) v2 系（本アプリと同じ PC で動かす）
- OBS Studio 28 以降（配信開始/終了の自動検知に使用。任意）

### インストール時の注意

`InfTimestamper-win-Setup.exe` を実行すると **「WindowsによってPCが保護されました」** と表示されます。個人開発の無償ツールのためコード署名証明書を取得しておらず、Windows SmartScreen が警告を出すためです。

続けるには **「詳細情報」→「実行」** を選択してください。ソースコードはすべてこのリポジトリで公開しています。
