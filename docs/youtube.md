# YouTube の概要欄の自動更新

記録中のタイムスタンプを、YouTube ライブ配信の概要欄へ自動で書き込む機能の使い方です。

- 記録中（`記録中` 状態）に、**配信開始時間とほぼ同時刻（前後 10 分以内）に始まった自分のライブ配信**を探します
- 見つかったら、その概要欄の**末尾**にタイムスタンプを書き込み、プレイが増えるたびに書き直します
- 記録を停止すると、その時点の最終版を書き込みます
- 対象は**配信中のライブだけ**です。配信が終わったあと（アーカイブ）に書き込むことはありません

## 必要なもの：OAuth クライアント

YouTube の概要欄を書き換えるには、Google の API を使うための「OAuth クライアント」が必要です。
INF-TIMESTAMPER は OAuth クライアントを同梱していないので、**各自で 1 回だけ作成**してください。
（API の利用量はクライアントごとに数えられるため、利用者全員で上限を分け合わずに済みます。）

無料で作成できます。請求先アカウントの登録も不要です。

### 1. Google Cloud のプロジェクトを作る

1. [Google Cloud コンソール](https://console.cloud.google.com/) を開き、配信に使う Google アカウントでログインします
2. 画面上部のプロジェクト選択 →「新しいプロジェクト」で、任意の名前（例：`inf-timestamper`）のプロジェクトを作ります

### 2. YouTube Data API v3 を有効にする

1. 「API とサービス」→「ライブラリ」を開きます
2. `YouTube Data API v3` を検索して「有効にする」を押します

### 3. OAuth 同意画面（Google Auth Platform）を設定する

1. 「API とサービス」→「OAuth 同意画面」（または「Google Auth Platform」）を開きます
2. アプリ名（例：`inf-timestamper`）とユーザーサポートメール（自分のメールアドレス）を入力します
3. 対象（ユーザーの種類）は **「外部」** を選びます
4. 連絡先のメールアドレスを入力して作成します
5. **「ブランディング」**の画面で次の項目を入力して保存します（本番環境への切り替えに必要です）

   | 項目 | 入力する値 |
   | --- | --- |
   | アプリのホームページ | `https://github.com/Freedom645/inf-timestamper` |
   | アプリのプライバシー ポリシーのリンク | `https://github.com/Freedom645/inf-timestamper/blob/main/docs/privacy.md` |
   | 承認済みドメイン | `github.com` |

   利用規約のリンクとロゴは空のままでかまいません（ロゴを設定すると審査が必要になるので、設定しないでください）

6. 「対象」（Audience）の画面で **「アプリを公開」** を押し、公開ステータスを「本番環境」にします

> [!IMPORTANT]
> 公開ステータスが「テスト」のままだと、**ログインが 7 日で切れます**（Google の仕様）。
> 自分だけで使う場合も「本番環境」にしておくことをおすすめします。
> その代わり、ログイン時に「Google はこのアプリを確認していません」という警告が出ます（下記）。

> [!NOTE]
> 公開後、Google の審査（検証）の画面に「ホームページの所有権を確認する必要がある」「プライバシー ポリシーを確認できない」
> などの指摘が出ることがあります。これは**審査を申請する場合の要件**で、自分だけで使う分には**対応も審査の申請も不要**です
> （github.com の所有権は証明できないため、対応しようとしても通りません）。
> 「対象」の画面で公開ステータスが「本番環境」になっていれば、そのまま次へ進んでください。
>
> 「テスト」のままで使う場合は、「対象」の画面の「テストユーザー」に自分の Google アカウントを追加してください。
> 7 日ごとにメイン画面に「再ログインが必要です」と出るので、設定画面でログインし直します。

### 4. OAuth クライアントを作る

1. 「API とサービス」→「認証情報」（または Google Auth Platform の「クライアント」）を開きます
2. 「認証情報を作成」→「OAuth クライアント ID」を選びます
3. アプリケーションの種類は **「デスクトップ アプリ」** を選び、任意の名前を付けて作成します
4. 表示された **クライアント ID** と **クライアント シークレット** を控えます

## INF-TIMESTAMPER での設定

1. 「ファイル」→「設定...」→ **「YouTube 連携」タブ**を開きます
2. クライアント ID とクライアント シークレットを貼り付けて「ログイン...」を押します
3. ブラウザが開くので、配信に使う Google アカウント（ブランドアカウントの場合はそのチャンネル）を選びます
4. 「Google はこのアプリを確認していません」と出たら、「詳細」→「inf-timestamper（安全ではないページ）に移動」で進みます
   （自分で作った OAuth クライアントなので問題ありません）
5. YouTube アカウントの管理を許可します。「認可の処理が終わりました」と表示されたらブラウザのタブは閉じてかまいません
6. 設定画面に「ログイン中: チャンネル名」と出れば完了です
7. **「ライブ配信の概要欄をタイムスタンプで自動更新する」にチェックを入れて「確定」**します

ログイン情報は Windows の DPAPI で暗号化して `%APPDATA%\inf-timestamper\youtube_credential.bin` に保存します
（同じ Windows ユーザでしか復号できません。`settings.json` には書きません）。

## 概要欄の書き換え方

概要欄の中の**見出し行**（既定：`▼タイムスタンプ`）から末尾までを、タイムスタンプで置き換えます。
見出し行が無ければ、概要欄の末尾に見出し行ごと追記します。

```
今日は皆伝を目指します！           ← 手書きの説明文はそのまま残る

▼タイムスタンプ                      ← ここから下を INF-TIMESTAMPER が書き換える
00:00:00 配信開始
00:05:12 灼熱 Pt.2 Long Train Running [SPA 12]
00:09:40 Verflucht [SPA 12]
```

- 手書きの説明文は**見出し行より上**に書いてください。見出し行より下に書いた内容は上書きされます
- 書き込む内容は「コピー」ボタンでコピーされる内容と同じです（フォーマットの設定がそのまま使われます）
- プレイがまだ 1 件も無いうちは書き込みません
- 概要欄の上限（5000 バイト）を超える場合は、新しい行から省略します
- `<` `>` は YouTube の概要欄に使えないため、全角の `＜` `＞` に置き換えます

## 更新の頻度と API の上限

YouTube Data API には 1 日あたりの利用上限（既定 10,000 ユニット）があり、概要欄の書き換えは 1 回で 50 ユニットを使います。
そのため、プレイ開始・リザルト・時刻の編集のたびに書き込むのではなく、**最短でも「更新間隔」（既定 60 秒）あけて**書き込みます。
間引いている間の変更は、次の書き込みでまとめて反映されます。記録を停止したときは間隔を待たずに書き込みます。

目安として、60 秒間隔で 3 時間配信し続けても約 180 回（9,000 ユニット）に収まります。上限に達した場合は、
その記録ではそれ以上書き込まず、メイン画面に「API の上限に達したため停止」と表示します
（上限は太平洋時間の 0 時、日本時間の 16 時または 17 時にリセットされます）。

## 状態表示

有効にしていると、メイン画面の「状態」の右に YouTube 連携の状態が出ます。

| 表示 | 意味 |
| --- | --- |
| 待機中 / 未ログイン | 記録中でない / ログインしていない |
| 配信を検索中 | 配信開始時間に対応するライブを探しています（YouTube 側で配信中になるまで少し遅れるため、30 秒ごとに探し直します） |
| 連携中（配信タイトル） | 対象のライブが見つかりました |
| HH:mm:ss に更新（配信タイトル） | 最後に概要欄を書き込んだ時刻 |
| 対象の配信が見つかりません | 前後 10 分以内に始まった配信中のライブがありません。この記録では書き込みません |
| 更新に失敗（再試行します） | 通信エラー等。次の間隔で書き直します |
| API の上限に達したため停止 | 上記の API 上限に達しました |
| 再ログインが必要です | ログインが切れています。設定画面でログインし直してください |

失敗しても配信の記録には影響せず、ダイアログも出しません（詳細はログに残ります）。

## ログアウト

設定画面の「ログアウト」を押すと、Google 側のトークンを失効させ、保存したログイン情報を削除します。
Google アカウントの [サードパーティのアクセス](https://myaccount.google.com/connections) からもアクセス権を削除できます。
